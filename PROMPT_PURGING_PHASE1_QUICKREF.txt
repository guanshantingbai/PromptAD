📋 核心思想
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
在正常样本上系统性误伤的 anomaly prompts → 候选清洗对象

🎯 分析对象
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
✓ 每条 manual anomaly prompt (逐条分析，不取均值)
✓ 只用正常样本 (训练集 + 测试集)
✓ 按类别独立分析

📊 关键指标
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
对每条 prompt p_j：

  margin: m_j(x) = s_n(x) - s_a_j(x)
  
  R_j_0       = P(m_j < 0)      严重误伤率
  R_j_eps     = P(m_j < ε)      主要风险指标 (ε=0.05)
  median(m_j)                   典型 margin
  q10(m_j)                      最坏情况

🚀 快速使用
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
python prompt_purging_phase1.py \
  --dataset mvtec \
  --class bottle \
  --k_shot 2 \
  --ckpt output/mvtec/bottle/k_2/best.pth \
  --epsilon 0.05

📂 输出文件
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
result/prompt_purging/phase1/{dataset}/k_{k_shot}/{class}_phase1_normal_side_risk_eps{eps}.csv

每行 = 一条 prompt，包含：
  - R_j_0, R_j_eps (风险指标)
  - median_margin, q10_margin, mean_margin, std_margin
  - risk_level (high/medium/low)

🔍 结果解读
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
高风险 prompt (R_j_eps 在 top 20%):
  → 大量正常样本被误判为接近异常
  → 语义可能过于模糊或与正常相似
  → 是 ablation 测试的候选

示例:
  [ 4] R_eps=0.234 | R_0=0.123 | median=2.45 | "blemished bottle"
       23.4% 正常样本 margin < 0.05
       12.3% 正常样本 margin < 0

⚠️ 重要说明
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
❌ 不做:
  - 不使用异常样本
  - 不做 fusion/AUROC/分类
  - 不做任何删除或权重调整

✅ 只做:
  - 正常侧失配诊断
  - 生成候选列表
  - 为下一阶段 (ablation) 准备

Phase 1 → Phase 2 (Prompt Ablation)
  
  对每个高风险 prompt:
    1. 在 CSV 中设置 enabled=False
    2. 重新测试整体 AUROC
    3. 如果 AUROC 上升 → 确认删除
    4. 如果 AUROC 下降 → 保留或多原型优化
